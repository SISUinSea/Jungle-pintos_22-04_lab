``` c
find_fd_entry(int fd) {
    - fd가 2보다 작으면 return
    - fd_table을 순회하며, file_elem으로부터 fd_entry를 꺼낸다.
    - 찾고자 하는 fd와 fd_entry->fd가 동일하면 후자를 반환한다.
    - 끝까지 없으면 NULL을 반환한다.
}
```
SYS_OPEN:
    - 인자로 들어온 file 이름으로 파일을 열어 파일 상태를 받는다.
    - fd_entry를 동적 할당한다.
    - fd table을 순회하며 가장 큰 값을 찾는다.
    - 가장 큰 값에서 1을 더한 값으로 fd를 배정한다.
    - 새로 만든 fd_entry를 fd_table에 매단다.
    - rax에 fd를 대입해 open이 반환하도록 한다.

SYS_CREATE:
    - 인자로 파일 이름과 파일 크기를 받는다.
    - filesys_create(file_name, initial_size) 함수로 파일 상태를 받는다.
    - 반환된 성공 여부를 rax에 넣고 break 한다.

SYS_CLOSE:
    - 인자로 fd를 받는다.
    - fd_lookup으로 entry를 찾는다.
    - file_close(file)로 파일을 닫는다.

SYS_FILESIZE:
    - 인자로 fd를 받는다.
    - fd lookup으로 entry를 찾는다.
    - file_length(file)로 열린 파일의 크기를 반환한다.
    - rax에 넣고 break 한다.

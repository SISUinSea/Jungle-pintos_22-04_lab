# syscall.c
``` c
find_fd_entry(int fd) {
    - fd가 2보다 작으면 return NULL
    - fd_table을 순회하며, file_elem으로부터 fd_entry를 꺼낸다.
    - 찾고자 하는 fd와 fd_entry->fd가 동일하면 후자를 반환한다.
    - 끝까지 없으면 NULL을 반환한다.
}
```

SYS_EXIT:
- 현재 스레드의 상태와 이름을 출력하고
- thread_exit을 호출한다.

SYS_OPEN:
- 인자로 들어온 file 이름으로 파일을 열어 파일 상태를 받는다. (filesys_open)
- fd_entry를 동적 할당한다.
- fd table을 순회하며 가장 큰 값을 찾는다.
- 가장 큰 값에서 1을 더한 값으로 fd를 배정한다.
- 새로 만든 fd_entry를 fd_table에 매단다.
- rax에 fd를 대입해 open이 반환하도록 한다.

SYS_CREATE:
- 인자로 파일 이름과 파일 크기를 받는다.
- filesys_create(file_name, initial_size) 함수로 파일을 만든다.
- 반환된 성공 여부를 rax에 넣고 break 한다.

SYS_CLOSE:
- 인자로 fd를 받는다.
- find_fd_entry으로 entry를 찾는다.
- fd_table에서 list_remove (file_elem);
- file_close(file)로 파일을 닫는다.
- free를 해준다.

SYS_FILESIZE:
- 인자로 fd를 받는다.
- find_fd_entry으로 entry를 찾는다.
- file_length(file)로 열린 파일의 크기를 반환한다.
- rax에 넣고 break 한다.

SYS_READ:
- 인자로 int fd, void *buffer, unsigned size 를 받는다.
- fd가 표준 입력인 경우에는 버퍼에서 꺼내오고 rax로 size를 반환하며 break.

- off_t file_read (struct file *file, void *buffer, off_t size); 사용하기 위해 file이 필요함
- fd를 인자로 받으므로, find_fd_entry로 fd_entry 찾음
- fd_entry->file로 file_read 진짜 사용
- rax에 넣고 break 한다.

# process.c
process_exit:
- fd table을 순회하며, elem으로 접근한 entry들을 list_remove, file_close, free를 사용하며 청소한다.
- 반복문 안에서 elem을 계속 지우기 때문에 for문 대신 while문 사용
